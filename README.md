# Consistent Hashing with Go

『가상 면접 사례로 배우는 대규모 시스템 설계』를 읽으며 **안정 해싱(Consistent Hashing)** 을 직접 구현하고 실험하는 프로젝트입니다.

노드가 추가되거나 제거될 때 전체 키를 재배치하지 않고, 영향을 받는 일부 키만 이동하는 원리를 Go로 확인합니다.

## 학습 목표

- 해시 링(Hash Ring) 기반의 키-노드 매핑 이해
- 노드 추가·삭제 시 키 재배치 범위 확인
- 가상 노드(Virtual Node)를 통한 데이터 분산 개선 이해
- 캐시, 샤딩, 분산 스토리지에 적용되는 안정 해싱의 활용 방식 학습

## 핵심 개념

일반적인 `hash(key) % N` 방식은 노드 수 `N`이 바뀌면 대부분의 키가 다른 노드로 이동합니다.

반면 안정 해싱은 노드와 키를 동일한 해시 링 위에 배치하고, 각 키를 시계 방향으로 가장 가까운 노드에 할당합니다. 따라서 노드가 추가되거나 제거되어도 해당 노드 주변의 일부 키만 재배치됩니다.

```text
key -> hash(key) -> hash ring에서 시계 방향의 첫 번째 노드
```

## 예제에서 확인할 것

- 초기 노드에 키가 어떻게 분배되는지
- 노드를 추가했을 때 어떤 키만 새 노드로 이동하는지
- 노드를 제거했을 때 해당 노드의 키가 어디로 이동하는지
- 가상 노드 수에 따라 분포가 어떻게 달라지는지
